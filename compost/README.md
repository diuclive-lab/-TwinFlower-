# 土壤层 — 66 → TwinFlower 养分体系

66 在双生花中不是根、不是茎、不是花，而是**演化土壤**。

```
TwinFlower 五层体系:

Root       = 模型能力
Stem       = 原子工具
Vascular   = 工具使用知识 (skills)
Flowers    = 日常/探索行为
66         = 演化土壤
```

66 为双生花提供四种生长物质，对应四个子目录：

| 目录 | 养分 | 性质 | 迁移策略 |
|------|------|------|----------|
| `nutrient/` | 矿物质 | 可直接移植的代码 | ROOT-READY → stem/tools, internal/ |
| `lessons/` | 腐殖质 | 失败经验沉淀的认知模型 | 不搬代码，搬决策逻辑 |
| `anti_patterns/` | 毒素标记 | 禁止迁移的模式 | 标红，形成 architectural guard |
| `decision_history/` | 菌根网络 | 隐藏知识、架构记忆 | 记录决策上下文和失败边界 |

**核心原则：双生花吸收 66 的生长经验，但不继承它的形态。**
