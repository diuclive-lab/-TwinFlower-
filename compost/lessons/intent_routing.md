# Intent Routing 失败教训

## 66 经历

66 尝试了多轮意图路由优化：关键词匹配、模型分类、confidence threshold、router A/B。

## 问题

- **中文自然语言模糊是结构性问题**，不是路由策略能解决的
- **关键词路由脆弱**："查一下"可以是搜索、天气、文件，取决于上下文
- **A/B 测试路由策略**优化的是路由本身，而不是用户意图的澄清

## 在双生花中的转化

66 试图让路由更准。双生花承认模糊是常态，转向：

```
66:   让路由更精准
TF:   让系统在不确定时会问
```

具体体现：

- **Adaptive Clarify**：根据 preference confidence 自动决定是否澄清
- **三层决策系统**：直接执行 / soft execute / formal clarify
- **Preference learning**：用户纠正后自动调整

## 结论

意图路由的瓶颈不在路由算法，在系统是否承认"我可能理解错了"。承认不确定并优雅处理它，比优化路由准确率更有价值。
